# Déclaration d'usage de l'IA générative

Le cahier des charges autorise l'IA générative comme outil, **à déclarer** (p.12). Ce registre est tenu à jour par l'équipe. Chaque membre doit pouvoir expliquer tout le code du dépôt, quelle que soit son origine.

La classification des documents est réalisée par un modèle entraîné par l'équipe. Aucun LLM ne décide de la classe d'un document.
